# TERRA

UI-first Android + iOS sandbox. **Not** production architecture.

Core globe = WebGL2 shader port of locked `render_globe` (C3 Soft Hollow + UI-2.5 numbers).
Delivery = thinnest Expo/WebView shell that yields an Android APK; same globe is iOS-ready.

MVP: S0 → S1 → S3 → S5. MOCK data only — never real demographics.

Lock pack in `lock/`. Geo textures in `assets/`.
